## 📌 Descripción del Proyecto
FocusClass es una solución informática desarrollada en Python orientada a combatir la procrastinación y el *doomscrolling* en estudiantes universitarios. El sistema permite procesar transcripciones extensas de clases grabadas (`.txt`), extrayendo automáticamente las ideas principales mediante un algoritmo de puntuación de oraciones y frecuencias léxicas, permitiendo un repaso ágil y efectivo.

## 🚀 Funcionalidades Principales
1. **Procesamiento de Transcripciones:** Análisis automatizado de archivos `.txt` descartando palabras vacías (*stopwords*).
2. **Generación de Resúmenes:** Extracción de las oraciones con mayor relevancia informativa.
3. **Módulo de Gamificación y Enfoque:** Sistema de puntos de recompensa por cada clase asimilada para incentivar el estudio.
4. **Persistencia de Datos:** Almacenamiento local en formato `.json` para registrar el historial de avance del estudiante.
